# ☕ Viaje Eje Cafetero — App de Presupuesto y Ahorro

App instalable (PWA) para planear y ahorrar para el viaje a:
**Parque del Café · Valle del Cocora · Salento**

## 📱 Cómo instalarla en tu celular desde GitHub Pages

### Paso 1 — Subir a GitHub
1. Crea un repositorio nuevo en [github.com](https://github.com) (ej. `eje-cafetero`)
2. Sube todos estos archivos tal como están

### Paso 2 — Activar GitHub Pages
1. En tu repositorio ve a **Settings → Pages**
2. En *Source* selecciona **Deploy from a branch**
3. Selecciona la rama `main` y carpeta `/ (root)`
4. Haz clic en **Save**
5. Espera ~1 minuto y GitHub te dará una URL tipo:
   `https://TU_USUARIO.github.io/eje-cafetero/`

### Paso 3 — Instalar en el celular
#### Android (Chrome):
1. Abre la URL en Chrome
2. Verás un banner *"Agregar a pantalla de inicio"* — tócalo
3. O toca el menú ⋮ → *Instalar aplicación*

#### iPhone (Safari):
1. Abre la URL en Safari
2. Toca el botón compartir 📤
3. Selecciona *"Agregar a pantalla de inicio"*
4. Toca *Agregar*

¡Listo! La app aparece como ícono en tu pantalla y funciona sin internet 🌿
